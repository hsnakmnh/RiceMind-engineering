# 与原版 RiceMind 的差异

核对日期：2026-11-27。独立工程适配，含会影响结果的策略变化。

## 基线

- 原项目：https://github.com/muhaha2/RiceMind
- 原始 RiceMind-main.zip SHA256：a53902a5045e9fcba1b6c8541e189ac9466106d3c66a43bb9e58b36bad774e80
- ZIP 有 24 个 Python、2 个 shell；未确认对应 Git 提交，不以文件日期伪造版本。
- 作者另给 PhraseMatcher 文件 SHA256：014e8519fde4df24cb8d0dea95d21f97b9e7872db4829cc62b301c018d2e4be5
- [逐文件审计](UPSTREAM_FILE_AUDIT.tsv) 列出基线、工作副本、候选哈希，候选源码增加的修改通知也改变字节哈希。

## 模块对照

| 模块 | 原版 | 当前变更 | 影响 |
|---|---|---|---|
| 配置/入口 | 多处固定服务器路径 | 中央配置、环境文件、统一入口、五轮脚本 | 工程组织，需确保读取同一批内容 |
| OGER call_oger | 原标注调用主体 | 配置导入与包/结果路径 | 同名函数 AST 核对一致；不同词典/包版本仍可能改变结果 |
| SciSpacy 五脚本 | 分词+EntityRuler | 模型、词典、输入、输出配置 | 五个 main AST 核对一致，仍禁用神经 NER 等 |
| keyword_filter.py | 作者规则和判定 | 路径和说明 | 判定与规则赋值 AST 一致 |
| 前置筛选适配器 | 基线没有年度 TSV 接口 | 复用作者判定，加长度限制、JSON/TSV/年份表 | 流程位置/句长/集合需记录 |
| PubTator 转句子 | 基线没有该环节 | 补充分句、清理、去重、标题与日期入口 | 影响边界/集合，非作者原分句复现 |
| PhraseMatcher 格式 | 作者另给 Pipeline | 列顺序、八列字符坐标、独立接入 | 原坐标是 token，不能混用 |
| PhraseMatcher 匹配 | en_core_web_md、第三列词汇、冲突后值 | blank、标准名+同义词、冲突保留首次 | 可能改变匹配，兼容选项也不能完全恢复全部行为 |
| remove_noise | 原有18个 variety ID | 外置六类规则、精确文本、副本/审计 | 外置为工程，新增规则会改结果 |
| gene 数字规则 | 基线没有 | 对特定 ID 下1/2/3精确排除 | 本地扩展，非原作者默认规则 |
| annotations_statistics | 原输入与统计结构 | 重写五轮嵌套/全句分母/去重/坐标/审计 | 统计口径不能默认等价 |
| 官方下载/组学 | 原 extract_local_omics | manifest 下载器/新生成器 | 参考快照/解析范围影响主表 |
| universal 主表 | 原别名整合 | 保留多候选、无RAP、补充条目 | 改变歧义处理 |
| NLP 关联 | 原句内笛卡尔积和 NLP_Cooccurrence | 保持共现，候选保留、默认关名字回退、规则/审计 | 映射/排除/聚合可能不同，不加因果判定 |
| 核查准备 | 原版无 | 哈希、上下文、频次和抽样 | 只生成材料 |
| 覆盖比较 | 原精确集合/Venn | CLI、日志、独立目录、manifest | 保留Os前缀和精确ID对，无新本体对齐 |
| 差集导出 | 原版无 | 交并集与句子证据 | 不重做标注 |
| 文档/测试/发布 | 原版未覆盖当前流程 | 使用手册、基线、合成测试CI、忽略/归属 | 不证明研究准确率 |

## 边界

不将共现当因果，不将公共库差集当新发现。AI 初审建议未自动启用新规则或批量人工映射。作者部分人工处理未记录，无法精确复建。2026 Oryzabase 与作者2025快照不同。当前关联器已整合映射/Trend，旧 map_nlp_rap_id、add_trends_to_nlp 不再串联。

## 本次发布整理

独立目录集中代码与资源，原工作区未迁移或删除。新增 tools/prepare_sentence_data.py 复用现有分句/筛选器，提供已有筛选句子的无重分句入口，并生成年度 TSV、JSON 和年份表；增加来源清单、完整句子与参考运行附件。配置和入口默认采用 dict-dir 分类目录，统计器兼容平铺及 genes/ontology 布局。上述路径/包装改动不添加匹配或生物学过滤规则。原件与活动词典的差异、来源散列写入清单。此对照基于保存 ZIP，不对上游后续变化作未核实结论。
